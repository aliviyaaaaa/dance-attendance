# dance-attendance — ИИ-аналитик посещаемости студии Garage

Telegram-бот, который сам забирает данные из Impulse CRM и считает:

- **посещаемость групп за неделю**: просевшие 🔴, под наблюдением 🟡, растущие 🟢, отмены и замены, Excel со всеми группами;
- **посещения по каждому занятию и зарплату педагогов** за расчётный период (1–15, 16–конец месяца);
- **сверку сводки админов с CRM**: какие занятия расходятся и на сколько это меняет выплаты.

Все цифры считает код, без ИИ. Персональные данные клиентов не сохраняются: в базе только количество человек на занятии.

## Как пользоваться

В Telegram у бота есть кнопки: 📊 Отчёт, 👥 Группы, 💰 Зарплата, 🔍 Сверка, 🔄 Обновить.
Команды тоже работают: `/report 28.09`, `/visits 16.09-30.09`, `/visits сентябрь`, `/groups`, `/refresh`, `/check`.
Сводку админов можно просто прислать боту текстом, и он сам её сверит.

## Как запустить

Нужен Python 3.11+.

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env          # и заполнить: адрес и логин CRM, токен бота, свой Telegram ID
cp teacher_aliases.example.json teacher_aliases.json   # имена педагогов для сверки
.venv/bin/python -m scripts.backfill     # первая загрузка за 12 недель
.venv/bin/python -m app.bot              # запуск бота
```

Тесты: `.venv/bin/pytest`

## Где что менять

| Что | Где |
|---|---|
| Пороги статусов (просадка −25% и −3 чел., минимум 4 чел./занятие и т.д.) | `app/config.py`, блок «Пороги статусов» |
| Праздники | `app/config.py`, `HOLIDAYS` |
| Ставки педагогов | `app/config.py`, `PAY_RATES` |
| Как админы называют педагогов в сводках | `teacher_aliases.json` (не публикуется, пример — `teacher_aliases.example.json`) |
| Получатели отчётов | `.env`, `TELEGRAM_ALLOWED_USER_IDS`: Telegram ID через запятую |

**Как добавить нового получателя:** человек пишет боту `/start`, ID появляется в журнале бота
(`logs/bot_console.log`, строка «Игнорирую сообщение… id=…»). Допишите этот ID через запятую
в `TELEGRAM_ALLOWED_USER_IDS` в `.env` и перезапустите бота.

## Если сломалась выгрузка из CRM

У Impulse CRM нет официального API, бот использует внутренний API веб-интерфейса, и после обновления CRM он может сломаться.
Тогда бот пришлёт «❌ Выгрузка из CRM сломалась: <эндпоинт>, <что не так>».

1. Проверьте, что пользователь `analytics_bot` может войти в CRM через браузер (пароль не сменился, учётка не заблокирована).
2. Запустите разведку: `.venv/bin/python -m scripts.explore_api`. Она покажет, какой запрос и какие поля изменились.
3. Сверка загруженных данных с CRM: `.venv/bin/python -m scripts.verify_sync`.

## Как устроено

```
app/
  config.py        настройки, пороги, ставки
  crm_client.py    вход в CRM, разрешённые запросы (только чтение), повторы
  sync.py          загрузка из CRM в SQLite (data/garage.sqlite)
  metrics.py       расчёт метрик и статусов (чистые функции, покрыты тестами)
  attendance.py    показатели групп по неделям
  report.py        еженедельный отчёт: текст + Excel
  lessons.py       посещения по занятиям и зарплата педагогов
  admin_check.py   сверка сводки админов с CRM
  bot.py           Telegram-бот
scripts/           разведка API, первая загрузка, сверка, калибровка порогов
tests/             pytest
```

Правила подсчёта, согласованные со студией:
- занятие без посещений и без записей считается «пустым», а не состоявшимся;
- если у одного педагога несколько групп в одно время, это одно объединённое занятие;
- за замену платят тому, кто вёл занятие.
