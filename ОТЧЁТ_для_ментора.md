**Про безопасность.** В проекте включён «Enable automatic RLS», поэтому у новых таблиц
Row Level Security включается автоматически. Проверил прямо в базе: под ролью `anon`
(анонимный ключ проекта, которым пользуется публичный Data API) таблицы отдают
**0 строк**, под ролью `postgres` — все данные. То есть из публичного API данные
студии не читаются, читает только бот.

**Честно про ограничения**

- Railway изначально был невозможен: у них глобально отключена регистрация новых
  аккаунтов после инцидента 21 октября. Supabase выбрал как замену — тот же Postgres,
  код к провайдеру не привязан, при открытии регистрации в Railway переезд = одна
  строка в `.env`.
- Прямое подключение Supabase идёт по IPv6, у этой сети нет маршрута IPv6 — использую
  session pooler.
- Данные обновляются только когда бот обновляется из CRM (кнопка `/refresh` в Telegram
  или еженедельный отчёт). Автообновления по расписанию пока нет.
- База в облаке Supabase, сам бот по-прежнему работает на моём Mac — это отдельный
  следующий шаг.
