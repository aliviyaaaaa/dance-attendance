## База Postgres для дашборда

Готова 24.10.2026. Проект **garage-analytics** в Supabase (Free, без карты), регион
`eu-west-1` (Ирландия).

- Строка подключения лежит в `.env` как `DATABASE_URL` (в git не попадает).
- Используется **session pooler** (`aws-0-eu-west-1.pooler.supabase.com:5432`): прямое
  подключение у Supabase идёт по IPv6, а у этой сети нет маршрута IPv6 — проверил, не
  подключается.
- Таблицы лежат в **отдельной схеме `garage`**, а не в `public`. Публичный Data API
  Supabase отдаёт только `public`, а в `garage` права есть лишь у `postgres` — анонимный
  ключ проекта наши данные не видит (проверено запросом к `information_schema`).
- Что публикуется: `garage.studio_groups` (группы), `garage.group_week_stats` (показатели
  за неделю со статусом «просела / растёт / под наблюдением»), `garage.attendance_daily`
  (посещаемость по дням), `garage.studio_meta` (служебное). Готовые представления для
  дашборда: `garage.dashboard_groups` и `garage.dashboard_daily`.
- Публикация происходит сама: после обновления из CRM и после каждого отчёта.
  Вручную: `.venv/bin/python -m scripts.publish_pg`, проверка: `… -m scripts.publish_pg --check`.
- Публикация идемпотентна: повторный запуск обновляет те же строки, а не плодит дубли.

**Проверка «перезапуск — данные на месте» (24.10):** опубликовали, перезапустили бота через
`launchctl kickstart -k`, данные на месте — 41 группа, 1373 строки недельных показателей,
2531 строка посещаемости по дням, последний день 22.10.

**Что осталось:** сам дашборд (страница, которая читает `garage.dashboard_*`).

## Ограничения, которые остались

- **Данные обновляются только по команде `/refresh` в Telegram.** Автообновления нет.
  Если не нажать кнопку, база отстанет (23.10 она отставала на 6 дней).
- **Бот работает, пока Mac включён, не спит и есть интернет.** Это не сервер.
- **Ставки педагогов в `app/config.py` студией не подтверждены.** При числе людей больше 29
  ставка не задана — код помечает такое занятие как «❓ставка не задана».
- **Ключи лежат в трёх местах** (рабочая папка, бэкап, архив). При передаче папок наружу
  это риск; лишние копии `.env` можно удалить.
